# BuyLocate Website Prototype

This is a front-end prototype based on the September 2026 BuyLocate PRD.

Included:
- Home
- About
- Services
- How It Works
- Shipping Calculator
- Booking prototype
- Shipment Tracking prototype
- Find a Hub
- FAQ
- Blog
- Contact

Shipping Calculator:
The calculator is functional in the browser, including actual vs dimensional weight. Its monetary pricing formula is DEMO ONLY. For production, replace the JavaScript demo rate engine with the approved UPS rating API or BuyLocate-configured rate service.

Open `index.html` in a browser to preview.

Production items still required:
- UPS API credentials and permissions
- UPS-approved branding/relationship wording
- Payment gateway
- Founder information
- Support phone/WhatsApp
- Operating hours
- Supported currencies
- Shipping/refund/restricted-items/customs policies
